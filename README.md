# Convite Louise Victória — 15 anos

Site de convite para GitHub Pages.

## Arquivos

- `index.html` — estrutura e textos do convite.
- `style.css` — visual responsivo.
- `script.js` — contagem regressiva e botão de agenda.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde o endereço do GitHub Pages aparecer.

## Personalizar fotos

No `index.html`, procure os três blocos:

`<div class="photo"><span>ADICIONE UMA FOTO</span></div>`

Você pode trocar cada um por:

`<img class="photo-img" src="fotos/louise1.jpg" alt="Louise Victória">`

Depois crie uma pasta `fotos` no repositório e envie as imagens.

## Personalizar a lista de presentes

As categorias já estão criadas. Para transformar uma categoria em botão com link, substitua o conteúdo do card por um `<a href="...">`.
